# Starting point: comfortable vim basics, fluent in IDEs, no Helix yet

Zach knows vim's modes, hjkl, `dw`/`cw`/`dd`, `/` search and `:w`/`:q`, but not macros, registers
or text objects. He is very fluent in VS Code / Cursor. Helix 25.07.1 is installed with no config
and the tutor has not been done. This sets the floor: teach the selection → action model from
scratch, use vim commands only as contrast, and use IDE features (multi-cursor, fuzzy open,
go-to-definition) as the familiar reference point.

**Implications**: skip "what is a modal editor"; do not assume `ci(`-style text objects transfer.
First lessons target tutor chapters 1–3 (movement, selections, change). See [[MISSION.md]].
