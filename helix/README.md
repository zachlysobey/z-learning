# Helix

Learning the [Helix editor](https://helix-editor.com/) — a modal terminal editor
with selection-first editing (Kakoune-style, roughly "vim reversed": select,
then act).

This is a `/teach` workspace: short HTML lessons in `lessons/`, printable cheat
sheets in `reference/`, and the mission, resources, and glossary as Markdown at
the top level. Start with `MISSION.md`, then the newest lesson.

Quick links:

- `hx --tutor` — the built-in interactive tutorial
- [Keymap](https://docs.helix-editor.com/keymap.html) · [Migrating from Vim](https://docs.helix-editor.com/from-vim.html)
