Select, then act

There is always a selection. Movements move it; one key acts on it. Verified against the keymap for Helix 25.07.

Make a selection

w / b / eto next word start / prev word start / next word end
W / B / Esame, but WORDs (whitespace-delimited)
xcurrent line; again = extend one more line
Xextend selection to line bounds
%entire file
fc / tcto / till next char c (crosses lines)
vselect mode: movements extend instead of replace
3wcounts work: three words

Adjust a selection

;collapse to a single cursor
Alt+;flip cursor and anchor
,keep only the primary selection

Act on it

ddelete
cchange (delete + insert mode)
y / p / Pyank / paste after / paste before
i / ainsert before / after the selection
I / Ainsert at line start / line end
u / Uundo / redo

Goto (g prefix)

gh / glline start / line end
gsfirst non-blank char
gg / gefile start / file end
