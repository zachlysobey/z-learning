# Notes

Working notes and user preferences for teaching climbing volumes. Not a lesson log.

## Situation (2026-09-01)

- Workspace: unfinished basement.
- Tools: drill, impact driver, basic hand tools. No saw of any kind.
- Materials on hand: some T-nuts and hardware; wall panels bought from now-defunct climbing gyms
  (presumably textured 3/4" ply with T-nuts, to be confirmed); two rough, unfinished plywood
  triangle volumes bought from a Facebook Marketplace seller.
- US-based: use inches first, millimetres in parentheses. 3/4" nominal ply is usually 23/32" (~18 mm).

## Preferences

- Small attainable milestones, but wants fundamentals, not a rush to a first output.
- Hands-on bandwidth may be limited for stretches; don't assume a build happened between sessions.
  Ask, and prefer lessons that work as "inspect / measure / plan" when no shop time is available.
- Interested in "handy" skills generally; explaining the woodworking *why* is welcome.
- Possible side-hustle later: note where home-wall shortcuts would not pass for a sellable volume.
- Don't propose buying tools until a lesson has justified the specific tool.
