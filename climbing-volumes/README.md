# Climbing volumes

Learning to build plywood climbing volumes for a home wall: anatomy, geometry and bevel angles,
cutting, joining, T-nuts, texture and paint, and mounting.

This is a `/teach` workspace: short HTML lessons in `lessons/`, printable cheat sheets in
`reference/`, and the mission, resources, and glossary as Markdown at the top level.
Start with `MISSION.md`, then the newest lesson.
