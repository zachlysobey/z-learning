# Agent notes — climbing-volumes

Notes while learning to build plywood climbing volumes. See `README.md` for the human-facing overview.

This directory is a **teaching workspace** driven by the `/teach` skill
(`.claude/skills/teach/SKILL.md` at the repo root). Read that skill before adding lessons.

## Layout

- `MISSION.md` — why Zach is building volumes. Grounds every lesson.
- `RESOURCES.md` — trusted sources. Every number in a lesson should trace to one of these.
- `GLOSSARY.md` — canonical terms; add a term only once Zach can use it correctly.
- `NOTES.md` — tools and materials on hand, teaching preferences, open questions.
- `lessons/NNNN-slug.html` — one short, self-contained lesson each; links `../assets/style.css`.
- `reference/*.html` — printable cheat sheets distilled from lessons; the thing revisited later.
- `assets/` — shared components (`style.css`, `quiz.js`). Reuse before writing new ones.
- `learning-records/NNNN-slug.md` — evidence of what was actually learned.

## Conventions

- Zach has no saw yet and limited shop time. Early lessons must be doable with a tape measure, a
  drill, and the volumes and panels already in the basement. Don't assume a build happened
  between sessions; ask.
- Inches first, millimetres in parentheses. Cite a source for any spec (thickness, screw size, ratio).
- Explain the woodworking reason, not just the climbing convention; "handy skills" are part of the mission.
- Open the finished lesson with `open lessons/NNNN-slug.html`.
