# Agent notes — z-learning

This is a personal learning repo: notes and experiments, one topic per top-level directory.

## Conventions

- Each topic directory has its own `README.md` (human context) and `AGENTS.md` (agent context, symlinked as `CLAUDE.md`).
- Keep the root `README.md` contents list up to date when adding a new topic directory.
- Commit messages: short and plain; this is a notes repo, not a codebase.

## Publishing (GitHub Pages)

The site is generated by `tools/build-site.py` into `_site/` and deployed on every
push to `main`. It is zero-config: topics and lessons are discovered, never listed.

- A top-level directory with a `README.md` becomes a topic landing page. Its title
  and blurb are that README's first heading and first paragraph — keep both tight.
- `lessons/*.html` and `reference/*.html` are listed automatically; each page's
  `<title>` and `<p class="subtitle">` become its link text and one-line summary.
- Topics without lessons still get a landing page listing whatever they do have.
- A `*.pdf` is published only if a matching `*.tex` sits beside it. This is what
  keeps source material (reference books, scans) out of the public site — do not
  loosen it.
- Only `assets/`, `lessons/`, `reference/`, and built PDFs are copied. Markdown
  notes are linked back to GitHub rather than rendered.
- Accent colours come from each topic's `assets/style.css`; topics without one get
  a stable colour from a fallback palette.
- After changing lesson structure, run `python3 tools/build-site.py` and check
  `_site/` before committing.
