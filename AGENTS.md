# Agent notes — z-learning

This is a personal learning repo: notes and experiments, one topic per top-level directory.

## Conventions

- Each topic directory has its own `README.md` (human context) and `AGENTS.md` (agent context, symlinked as `CLAUDE.md`).
- Keep the root `README.md` contents list up to date when adding a new topic directory.
- Commit messages: short and plain; this is a notes repo, not a codebase.
